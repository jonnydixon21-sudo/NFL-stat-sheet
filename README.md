# NFL Stat Sheet

NFL stats and betting picks for the 2026 season: team best/worst 5, player leaderboards, weekly matchups with projections, top 5 picks (anytime TD, spread, over/under, moneyline) and a bet tracker.

Open it here: https://jonnydixon21-sudo.github.io/NFL-stat-sheet/

## Install it as an app
- **iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the link in Chrome, tap the ⋮ menu, then **Install app** (or Add to Home screen).

It opens full screen with its own icon. Stats refresh every Wednesday, and the app picks up the new week the next time you open it. Bets you track are saved on your own phone.

A guide, not a guarantee. Please bet responsibly.
